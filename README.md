# 霍墨墨的 AI Infra 博客

基于 Astro 构建的个人技术博客，面向 AI Infra、训练优化、推理优化方向的学习与对外展示。

## 本地启动

使用 Node.js 24 LTS（最低版本 22.12）。

```bash
npm ci
npm run dev
```

默认预览地址为 `http://localhost:4321`，也可以使用 TRAE 的运行按钮启动。

## 构建

```bash
npm run check
npm run build
```

## 界面与文章组织

- 首页展示知识分类和最近发布的 5 篇笔记。
- `/blog/` 是分类总览，每类最多展示最新 5 篇；支持标题、摘要、分类搜索及分类筛选，搜索结果每页 10 篇。
- `/topics/<分类>/` 为分类详情，每页 10 篇，按发布时间降序排列。分页是构建时生成的静态页面，无需 JavaScript。
- 搜索关键词、分类和页码保存在 URL 中，支持刷新和分享；按 `/` 可以聚焦搜索框。
- 文章页提供章节目录、移动端折叠目录、代码复制、同分类上一篇和下一篇。
- 新增文章仍放在 `src/content/blog/`，现有 Markdown 格式和 `/blog/<文章名>/` 链接不变。
- 分类定义及数量上限统一维护在 `src/lib/blog.ts`，未知分类会自动生成独立分类入口。
- 网站日期按北京时间显示，避免本地与 CI 构建时区造成日期差异。
